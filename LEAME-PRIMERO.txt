EVENTIFY - INSTALACIÓN EN WINDOWS

1. PREPARAR LA CARPETA
Extraiga todo el ZIP, por ejemplo en C:\Proyectos\EventifyEntrega.
No abra el instalador dentro del ZIP. Mantenga la carpeta en esa ubicación.
Necesita conexión a Internet para la primera instalación, Windows de 64 bits
compatible con Docker Desktop y virtualización habilitada. Docker indica
al menos 8 GB de RAM. Con menos memoria, el instalador muestra un aviso;
continuar no garantiza que Docker pueda funcionar correctamente.

2. INSTALAR
Abra INSTALAR-EVENTIFY.cmd con doble clic.
El asistente prepara los componentes necesarios, instala Docker Desktop
si hace falta y luego inicia Eventify. No necesita instalar PHP ni MySQL
por separado ni crear cuentas en los servicios de alojamiento.

Acepte el permiso de administrador cuando Windows lo solicite.
Si se pide reiniciar, reinicie el equipo y abra el mismo instalador otra vez.
Si Docker muestra sus condiciones de uso, revíselas para continuar.
Deje la ventana abierta hasta que termine. La descarga y la preparación
inicial pueden tardar varios minutos, según la conexión y el equipo.
Al finalizar, se abre http://localhost:8080 en el navegador.

3. INICIAR Y DETENER
La instalación crea dos accesos en el escritorio:
- Iniciar Eventify: inicia los servicios y abre la página.
- Detener Eventify: apaga el proyecto y conserva los datos.

También puede usar iniciar-windows.cmd y detener-windows.cmd dentro de
la carpeta Eventify. Si mueve la carpeta, abra nuevamente el instalador
para actualizar los accesos. Docker puede seguir abierto al detener Eventify.

4. CUENTAS DE ACCESO
Una instalación nueva incluye ocho eventos de ejemplo y dos cuentas:
- ADMINISTRADOR: permite gestionar eventos, categorías, reservas y usuarios.
- USUARIO: permite explorar eventos, reservar y consultar sus tickets.

Para ver los correos y las contraseñas, abra la carpeta Eventify, entre en
storage y abra example-credentials.json con Bloc de notas.
Busque cada cuenta por su campo role; email es el correo y password la clave.
Las claves se generan para esa instalación. Conserve el archivo en privado.
No hace falta volver a crear las cuentas y los reinicios no cambian sus claves.
Si la base ya contiene datos, el instalador los conserva.

5. COMPROBAR QUE FUNCIONA
Ingrese como usuario, reserve un evento y abra el ticket con su código QR.
Ingrese como administrador y revise los eventos y las reservas.
Detenga e inicie Eventify y compruebe que los datos siguen disponibles.
Los eventos son ejemplos académicos; la aplicación no recibe pagos reales.

6. PÁGINA LOCAL Y PÁGINA PÚBLICA
Esta copia funciona en su computadora. La dirección localhost solo abre
mientras el proyecto está encendido en ese equipo.
La página pública es https://eventify-academico.onrender.com.
Son instalaciones independientes: sus cuentas y reservas no se sincronizan.
Las claves de esta carpeta corresponden únicamente a la copia local.

7. SI ALGO FALLA
Si Docker aún está iniciando, espere a que esté listo y vuelva a iniciar Eventify.
Si se indica que el puerto 8080 está ocupado, conserve el mensaje del error.
No borre los datos ni reinstale todo como primer intento de solución.
No elimine los volúmenes de Docker: allí se guardan las cuentas y las reservas.
Copiar esta carpeta a otro equipo no copia las reservas ya realizadas.
Internet se necesita para el pronóstico; si falla, puede seguir reservando.
