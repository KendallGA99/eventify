EVENTIFY - SUBIR EL PROYECTO A GITHUB

Este paquete es para guardar el codigo y su historial en tu cuenta.
La instalacion de la aplicacion se entrega en otro ZIP.

1. Crea tu cuenta en github.com si todavia no tienes una.
2. Extrae todo este ZIP en una carpeta de tu computadora Windows.
3. Haz doble clic en PUBLICAR-EN-GITHUB.cmd. No necesitas abrirlo como administrador.
4. El asistente descarga Git y la herramienta oficial de GitHub. Necesita Internet.
5. Se abrira la autorizacion de GitHub. Inicia sesion con tu cuenta y autoriza.
   Si muestra un codigo de un solo uso, escribelo en la pagina oficial indicada.
   La contrasena se escribe solamente en GitHub, nunca en el CMD.
6. Revisa la cuenta que aparece en el CMD y escribe SI para continuar.
7. Espera a que termine. Se abrira tu repositorio con el proyecto y su historial.

No tienes que crear el repositorio antes ni copiar direcciones o comandos.
Se crea con el nombre eventify y es privado: solo lo ven tu y las personas
que invites. La rama inicial sera la version mas reciente de este paquete;
main conserva su posicion historica. Las ramas y etiquetas se conservan.
Las ejecuciones automaticas de GitHub quedan desactivadas en esta copia.

Si ya tienes un repositorio llamado eventify, el asistente se detiene sin
modificarlo. Usa una cuenta sin ese repositorio o cambia el nombre del existente
desde GitHub. No hace falta borrar nada.

Si se interrumpe la conexion, vuelve a abrir el mismo CMD en la misma computadora.
El asistente reconoce el repositorio que creo y comprueba su contenido antes
de continuar. Si encuentra cambios distintos, se detiene para conservarlos.
No borra repositorios y no reemplaza cambios con una subida forzada.

Para compartirlo con el profesor, abre el repositorio en GitHub, entra en
Settings > Collaborators y envia la invitacion a su cuenta. El tendra que
aceptarla. No compartas tu contrasena. Esta invitacion se hace por separado.

El historial conserva los aportes previos con el seudonimo Usuario win38;
no los atribuye a quien recibe el proyecto. La explicacion se conserva en
docs/PRIVACIDAD-HISTORIAL.md dentro del repositorio.

Este paquete no contiene las contrasenas de la aplicacion ni los datos MySQL.
Los enlaces que dicen USUARIO_DESTINO son marcadores pendientes de actualizar.
El asistente comprueba las ramas y etiquetas al terminar. La autenticacion
y publicacion completas deben confirmarse con la cuenta del receptor.

Las herramientas se descargan de sus proyectos oficiales con versiones y
huellas SHA256 fijadas. GitHub CLI usa licencia MIT y Git usa GPLv2.
No se cambian las herramientas ni la configuracion Git global del equipo.
La sesion de autorizacion de este asistente se cierra al finalizar.
