EVENTIFY - ENTREGA DEL PROYECTO

Esta entrega está organizada en tres paquetes:

01-INSTALACION
Extraiga el ZIP de esta carpeta en una ubicación definitiva y abra
INSTALAR-EVENTIFY.cmd. La guía LEAME-PRIMERO.txt explica los pasos,
los accesos Iniciar/Detener y dónde consultar las cuentas locales.
La aplicación incluye ocho eventos de ejemplo. No hace falta instalar
PHP ni MySQL por separado.

02-DOCUMENTACION
Contiene el documento técnico PDF, el manual de uso, la guía de demostración
y la lista de lo que se debe compartir con el profesor.

03-GITHUB
Extraiga el ZIP y abra PUBLICAR-EN-GITHUB.cmd. Inicie sesión con su propia
cuenta de GitHub y confirme la cuenta que muestra el asistente.
Se crea un repositorio privado con el código y el historial. La guía explica
cómo invitar al profesor. No se necesita GitHub para ejecutar Eventify localmente.

04-ACCESOS-PRIVADOS
Contiene las cuentas de evaluación de la página pública. Consérvelas en
privado y compártalas solo con el receptor y el evaluador. No suba esta carpeta
ni el ZIP principal completo a GitHub. El asistente de GitHub importa únicamente
el historial que viene en su paquete; no publica estos accesos.

PÁGINA PÚBLICA
https://eventify-academico.onrender.com

La página pública y la instalación local son independientes. Las cuentas,
las reservas y los eventos no se sincronizan. Las cuentas locales se generan
al instalar y se consultan en Eventify\storage\example-credentials.json.
Las cuentas públicas están en 04-ACCESOS-PRIVADOS.

ANTES DE ENTREGAR AL PROFESOR
Abra el documento técnico, compruebe la página pública y los accesos,
importe el historial a su cuenta de GitHub y conceda acceso al profesor.
Comparta el enlace del repositorio que muestra el asistente al terminar.
Practique el recorrido de demostración y la explicación del código.

La instalación dev.52 se probó después de borrar los contenedores, los datos
y las imágenes anteriores de Eventify, manteniendo Docker y WSL instalados.
La documentación del paquete se actualizó después de esa prueba.
El ZIP no contiene reservas existentes, una copia de Windows ni Docker instalado;
el asistente prepara las dependencias cuando sea necesario.
