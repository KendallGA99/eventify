# Configuración pública

La conexión MySQL del entorno público requiere TLS con validación del certificado y una CA montada en tiempo de ejecución. Los secretos se suministran mediante variables del servicio y no se incluyen en Git ni en las imágenes. Véanse [Despliegue](DESPLIEGUE.md), [Seguridad](SEGURIDAD.md) y [Configuración](../config/README.md).
