B07/SEG-09. Trece identificadores y setenta filas MEDIUM del escaneo PHP/Apache dev.32, repetidas principalmente en paquetes GCC. Código de aplicación/configuración igual en dev.33. Fuentes Debian y cotejo privados en storage/image-audit/tools-medium-review. La instalación de una biblioteca y la existencia de un servicio que la use se revisan por separado; no se excluyen avisos ni se modifican severidades.

## Cobertura y pendientes

La búsqueda de comandos se realizó en app/bin/public/docker/scripts y ambos Dockerfile. La ausencia de esas invocaciones describe código propio, no un análisis exhaustivo de llamadas nativas. Las herramientas de construcción y runtime del host siguen siendo ámbitos distintos de la aplicación.

Junto con AVISOS-BASE, AVISOS-APACHE-TAR y AVISOS-CURL, quedan documentados identificadores de las189 filas MEDIUM fuera de linux-libc-dev en la imagen PHP/Apache conservada. Las787 filas MEDIUM de linux-libc-dev corresponden a cabeceras: no representan un kernel ejecutándose dentro del contenedor, pero tampoco prueban que el kernel del host esté corregido. No se evaluaron individualmente esos787 avisos ni todos los avisos LOW. Los límites abiertos de bibliotecas nativas, curl/OpenSSL, DNS, discrepancias de versiones y host permanecen pendientes; cobertura documental no significa remediación.

No se alteraron paquetes, datos o servicios, ni se ejecutaron nuevas pruebas funcionales por esta revisión. Para dev.33 falta instalar el ZIP exacto y recorrerlo; Windows/Firefox/zoom y evidencia humana conservan sus pendientes.
