# EVENTIFY

Plataforma académica web para descubrir eventos, reservar entradas, consultar tickets digitales y administrar eventos, categorías y reservaciones.

## Estado actual

Planificación inicial. Todavía no existe una aplicación ejecutable, configuración Docker, suite de pruebas ni despliegue. El repositorio Git local existe; no hay remoto GitHub configurado al crear esta documentación.

## Condiciones acordadas

- Desarrollo en Linux y entrega para Linux y Windows.
- Ejecución local con Docker Compose; instalación y demostración documentadas.
- PHP, MySQL, HTML5, CSS3, JavaScript, jQuery y AJAX.
- Herramientas gratuitas para uso académico; no contratar servicios sin autorización.
- Aplicación responsiva, seguridad en servidor, pruebas y versionado progresivo.
- Publicación pública requerida por el enunciado; proveedor gratuito todavía por determinar.

## Secciones que se completarán durante el desarrollo

- Versiones y requisitos de Docker/Linux/Windows.
- Instalación, configuración y arranque por sistema operativo.
- URL local, cuentas de demostración y comandos de pruebas.
- Persistencia, exportación, restauración y resolución de problemas.
- Tecnologías, licencias, API externa y limitaciones de conexión.
- Enlaces al repositorio GitHub, sistema público y documento técnico final.

No ejecutar comandos de instalación hipotéticos: se incorporarán y verificarán cuando exista la implementación.
